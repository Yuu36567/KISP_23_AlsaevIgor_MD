# Создать проект

Expo - это структура React Native, которая облегчает разработку приложений для Android и iOS. Наша структура обеспечивает файловую маршрутизацию, стандартную библиотеку нативных модулей и многое другое. Expo - это открытый исходный код с активным сообществом на [GitHub](https://github.com/expo/expo) и [Discord](http://discord.com/).

Мы также делаем [Expo Application Services (EAS)](https://expo.dev/services), набор услуг, которые дополняют структуру Expo на каждом этапе процесса разработки.

    Новичок в программировании? Вы можете создать свое первое приложение Expo, предложив агенту кодирования ИИ вместо написания кода. Следуйте за сборкой с помощью учебника по ИИ. Он охватывает установку с нуля.

# Начните с проекта по умолчанию

Рекомендуем начать с созданного по умолчанию проекта create-expo-app. Проект по умолчанию включает в себя пример кода, чтобы помочь вам начать работу.

Чтобы создать новый проект, выполните следующую команду:
```
npx create-expo-app@latest --template default@sdk-58
```
    В течение переходного периода SDK 58, create-expo-app@latest Без --template Флаг создает проект SDK 57. Если вы планируете использовать Expo Go на физическом устройстве, используйте проект SDK 57. В противном случае используйте --template default@sdk-58 Создание проекта SDK 58. Вы также можете выбрать другой шаблон, добавив --template опция.

# Начните с примера

Вместо проекта по умолчанию вы можете начать с одного из примеров [Expo](https://github.com/expo/examples). Это небольшие приложения, каждое из которых демонстрирует определенную функцию или интеграцию, такие как Expo Router, Expo Widgets или экран камеры.

Чтобы просмотреть полный список и выбрать один в интерактивном режиме, запустите create-expo-app с --example Опция и отсутствие имени:
```
npx create-expo-app@latest --example
```
Чтобы создать известный пример напрямую, пропустите его имя:
```
npx create-expo-app@latest --example with-widgets
```

    Остальные руководства в этом разделе «Начать» следует проекту по умолчанию. Пример приложения может быть организован по-разному, но концепции одинаковы.


# Настройте агента ИИ

Новый проект включает AGENTS.md с контекстом проекта для агентов ИИ. Когда установлен код Клода, он также включает .claude/settings.json для включения плагина Expo. У Клода Кода и Кодекса есть официальный плагин Expo. С помощью одной команды вы можете установить [Expo Skills](https://docs.expo.dev/skills/) и зарегистрировать [сервер протокола контекста модели Expo (MCP)](https://docs.expo.dev/mcp/)
```
claude plugin install expo@claude-plugins-official
```

Затем бежать /mcp В вашем сеансе Claude Code для входа в вашу учетную запись Expo.

Плагин также устанавливает навык, который учит агента, где файлы живут в новом проекте Expo:
Для Cursor и других агентов установите [Expo Skills](https://docs.expo.dev/skills/) и [Expo MCP Server](https://docs.expo.dev/mcp/) отдельно. [Агенты ИИ](https://docs.expo.dev/agents/) и обзор [Expo](https://docs.expo.dev/agents/) охватывают настройки для каждого агента.
